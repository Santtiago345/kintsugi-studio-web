## Documentos previstos

A medida que avance el proyecto se agregarán:

- `REQUISITOS.md` — requisitos funcionales y no funcionales.
- `HISTORIAS-USUARIO.md` — historias, criterios de aceptación y priorización.
- `DOMINIO.md` — modelo de dominio, reglas y glosario.
- `ARQUITECTURA.md` — capas, componentes, patrones y diagramas.
- `API.md` — contrato REST y ejemplos de uso.
- `BASE-DATOS.md` — modelo relacional y migraciones.
- `PRUEBAS.md` — estrategia y cobertura.
- `DESPLIEGUE.md` — entornos, CI/CD y operación.

## Convenciones

- Idioma de trabajo: español.
- Código, nombres de entidades y mensajes de commit: inglés.
- Diagramas en Mermaid dentro de los documentos, para que se versionen como texto.
- Toda decisión técnica relevante se registra con su justificación y alternativas.
